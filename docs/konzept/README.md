## Google Stitch
Die vorhandenen Google-Stitch-Designvorlagen sind die verbindliche visuelle Referenz. Die eigentlichen Links, Screenshots und Assets sind nicht in diesem Paket enthalten und müssen zusätzlich bereitgestellt werden. Claude Code darf nicht behaupten, die Entwürfe gesehen zu haben, wenn sie nicht zugänglich sind.

## Hinweise
Wedora ist ein Arbeitsname; Marken- und Domainverfügbarkeit sind nicht geprüft. Symfony 8.1 ist die beschlossene Ausgangsbasis und muss vor Projektstart erneut auf Supportstatus und Kompatibilität geprüft werden. imgproxy OSS und Hovod sind vorgesehene selbst gehostete Dienste; Lizenz, Reifegrad, API und Wartung sind zu prüfen. Private HLS-Wiedergabe ist ein blockierendes Sicherheitskriterium.
